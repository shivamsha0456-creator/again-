Ek Khat 💌

Janta hoon ki tumhe thoda waqt lagega theek hone mein, par main tumhe aise udaas aur khafa nahi dekh sakta. Jab tak tum sach mein theek hokar, dil se khush hokar mujhse pyaar se "na" nahi keh deti, tab tak main haar nahi maanunga.

Main kuch na kuch karta rahunga, tumhe manata rahunga, tumhari narazgi ko samajhne ki koshish karta rahunga. Main tumhe force nahi karunga, bas tumhare saath rahunga aur jitna waqt lage, utna intezaar karunga.

Bas main chahta hoon ki tum phir se dil se muskurao, mere saath khush raho. Tumhari ek chhoti si muskaan bhi mere liye bahut kuch hai, aur jab tak woh wapas nahi aati, main apni taraf se koshish karta rahunga.
